# Changelog Dokumen Information Systems

Dokumen direvisi per sprint. Setiap perubahan penting dicatat di sini beserta alasannya, sehingga perubahan di tengah jalan dapat ditelusuri.

## v0.1 - Draft Fase 1

Dokumen awal disusun dari notes tim, Project Plan, dan proposal UI/UX UINIC 2025.

- Kebutuhan sistem: 26 kebutuhan fungsional, 6 non-fungsional, prioritas MoSCoW.
- Use case: 3 aktor (User, Admin, Model AI), 13 use case user, 8 use case admin.
- ERD: 14 tabel; kamus data.
- UI/UX: pemetaan frame Figma ke fitur, user flow, daftar layar yang belum ada.

Asumsi yang belum dikonfirmasi: A-01 sampai A-06 (lihat bagian 5 dokumen kebutuhan).

Keputusan pada draft ini:
- Platform web responsif (bukan mobile native), berbeda dari proposal UINIC yang membatasi pada mobile iOS.
- Event dibuat oleh user pada level tertentu, mengikuti notes (proposal UINIC melarang user membuat event).
